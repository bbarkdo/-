# 다이나믹웨이브 불당점 홈페이지 (천안 불당동 키즈 & 성인 프라이빗 수영장)

정적 사이트입니다. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
**일상적인 수정은 `data.js` 한 파일만** 고치면 됩니다. (`★` 표시 = 아직 임시값)

## 시간표 · 여석 바꾸기 (`classes`)
한 줄이 한 반입니다.
```js
{ type: 'baby', name: '유아반', level: '5~7세 · 물적응', days: ['월', '수'], time: '15:00', mins: 50, cap: 4, cur: 3 },
```
- `cur`(현재 인원)만 바꾸면 남은 자리가 자동 계산됩니다. `cap - cur`가 0이면 **마감 · 대기 접수**, 1이면 **마감 임박**.
- `type`: `baby` 유아반 / `elem` 초등반 / `private` 개인·소그룹 / `adult` 성인반 (색과 필터가 정해짐)
- 반을 새로 열면 줄을 복사해 추가, 없어지면 줄 삭제.
- 수정 후 맨 위 `updated` 날짜도 바꿔주세요. 시간표 위에 "○월 ○일 기준 여석"으로 표시됩니다.

## 방학특강 창 (`special`)
- `from` ~ `to` 기간에만 자동으로 띠 · 섹션 · 팝업이 나타나고, 기간이 지나면 자동으로 사라집니다.
- 당장 숨기려면 `show: false`, 팝업만 끄려면 `popup: false`.
- 부(시간대)마다 `cap`, `cur`로 여석 표시. 방문자가 "이 시간 신청하기"를 누르면 상담 신청서에 담깁니다.

## 가격 (`prices`, `priceNotes`)
탭 하나가 `{ label, desc, head, rows }`. 현재 금액은 전부 **예시**입니다.

## 사진
`assets/photos/`에 아래 이름으로 넣으면 자동으로 교체됩니다.
`pool.jpg`(전경), `kids-class.jpg`(유아반 수업), `lounge.jpg`(대기실), `shower.jpg`(샤워실), `dryer.jpg`(파우더룸)

## 대기 접수 · 상담 신청
- 휴대폰: 서식에 맞춰 작성된 문자가 `info.sms` 번호로 자동 입력됩니다.
- PC: QR 코드가 나오고, 휴대폰으로 찍으면 같은 문자가 작성됩니다.
- 시간표의 수업을 누르면 희망 시간(1·2·3순위)에 자동으로 추가됩니다.
